# Diagrammes TrainingHub

Les diagrammes Mermaid de ce dossier peuvent etre affiches directement dans
GitHub et reutilises dans le rapport PFE.

- `architecture.md` : architecture applicative et deploiement Kubernetes ;
- `business-flow.md` : sequence metier de bout en bout ;
- `ci-cd-pipeline.md` : chaine DevSecOps complete, du Shift Left a
  l'observabilite et a l'assistance AIOps.

Pour les exporter en PNG ou SVG, ouvrir le fichier dans GitHub ou dans un
editeur compatible Mermaid, puis utiliser sa fonction d'export. Verifier que les
textes restent lisibles avant de les inserer dans le rapport.
